# Test - Quarkus REST Basics

Dieses Repository ist Ihre Abgabe. Es ist absichtlich fast leer.

## So starten Sie

1. Klonen Sie dieses Repository.
2. Stellen Sie sich auf https://code.quarkus.io/ die Applikation zusammen, wie in der Angabe beschrieben, und laden Sie das ZIP herunter.
3. Entpacken Sie das ZIP und kopieren Sie den **Inhalt** des Projektordners in das Root dieses Repositories, sodass `pom.xml` direkt neben dieser `README.md` liegt. Die `README.md` aus dem ZIP darf diese hier überschreiben.
4. Committen und pushen Sie.

Löschen Sie nicht die Ordner und Dateien `.github/` und `.classroom50.yaml`. Ohne sie wird Ihre Abgabe nicht automatisch geprüft.

## Automatische Prüfung

Nach jedem Push startet eine automatische Prüfung. Sie baut Ihr Projekt, startet es mit `mvn quarkus:dev` und ruft die Endpunkte `/exercises`, `/training-plans` und `/training-exercises` so auf, wie die Angabe es festlegt.

- Ein Lauf dauert einige Minuten.
- Das Ergebnis sehen Sie unter **Releases** (rechts auf der Startseite des Repositories) und unter **Actions**.
- Die Punkte der automatischen Prüfung sind nicht Ihre Testnote. ERD, JPA, die weiteren Endpunkte und Ihre eigenen Tests beurteilt die Lehrkraft.
